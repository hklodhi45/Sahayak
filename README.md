# Sahayak
Sahayak is a cooperative gig-services platform that connects customers with
verified local workers and cooperatives for household and community services.

Customers can book services through:
- Cooperative-backed workers
- Independent workers

The platform provides smart worker matching, transparent profiles,
work distribution, service support, and real-time availability.

Built for Smart India Hackathon 2026 — SIH26089.
